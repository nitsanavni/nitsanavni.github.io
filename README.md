# nitsanavni.com

The blog at https://nitsanavni.com. Built with [Astro](https://astro.build), deployed on Cloudflare Pages.

- Posts: `src/content/posts/*.md` (frontmatter: `title`, `date`, optional `description`)
- Drafts: `in-progress/` (not built)
- Images: `public/images/`

```sh
bun install
bun run dev      # local preview
bun run build    # output in dist/
```
